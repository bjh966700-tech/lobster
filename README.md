# 🏃 바톤

> AI 대화, 맥락째로 이어 달리기

**AI와 나눈 대화를 프롬프트째로 공유하고, 팀원과 그 맥락 위에서 실시간으로 이야기하는 팀플 협업 플랫폼**

팀플 하다 보면 다들 AI 답변을 카톡에 복붙하고, 받은 사람은 그걸 또 자기 AI에 붙여넣어서 이해하죠.
바톤은 **프롬프트 + AI 답변 + 메모**를 카드 한 장으로 올리고 링크 하나로 공유합니다.
받은 사람은 맥락을 보고 버튼 하나로 자기 AI에게 이어서 묻거나, 카드 옆 채팅방에서 팀원과 바로 이야기할 수 있어요.

> 유레카프로젝트 2026-2 · 팀 랍스터 (변재엽 20262079, 김가윤 20262068)

## 기능 (Sprint 1)
- 📝 AI 대화 카드 만들기 → 공유 링크 자동 복사
- 👀 카드 보기: 메모 / 프롬프트 / AI 답변을 나눠서, 마크다운까지 보기 좋게
- 🤖 **AI용으로 복사**, **ChatGPT로 열기**, **Claude로 열기** — 맥락째로 내 AI에 넘기기
- 💬 **실시간 팀 채팅**: 카드마다 채팅방, 접속자 표시, 새로고침 없이 메시지 도착, 자동 재연결

## 기술 구성
Amplify Hosting(화면) · API Gateway HTTP API + WebSocket API · AWS Lambda(Node.js 24) · Amazon DynamoDB · CloudWatch

## 빠르게 실행해 보기 (AWS 없이)
```bash
npm install
npm run dev     # http://localhost:3000
npm test        # 자동 시험
```
